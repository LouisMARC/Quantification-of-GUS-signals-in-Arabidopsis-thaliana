# Quantification-of-GUS-signals-in-Arabidopsis-thaliana

Welcome to the GUS Quantification project! This repository contains ImageJ/Fiji scripts to automatically quantify GUS signal from leaves of *Arabidopsis thaliana*.

## Features

- **GUS_Quantification_Tool.ijm**: ImageJ/Fiji script for quantifying GUS signal from an image, starting with segmentation of the leaf blade.
